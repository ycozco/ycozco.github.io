# Yoset Cozco — Portafolio profesional

Repositorio fuente de [ycozco.github.io](https://ycozco.github.io/), un dossier profesional enfocado en proyectos de Ingeniería de Sistemas y desarrollo de software.

## Proyectos destacados

1. **QP Secure CRM** — SaaS multitenant, backend, realtime y seguridad de datos.
2. **SAS Gym** — plataforma SaaS full stack con PWA e infraestructura Docker.
3. **INFOUNSA** — case study de arquitectura modular, aplicaciones Electron y CI/CD.
4. **Agro-Intelligence Oversight** — software de IA aplicada para análisis FOB, detección de anomalías y explicabilidad.
5. **Decolumax Jardinería** — sitio web empresarial con Astro, SEO técnico y despliegue en VPS.

## Tecnologías representadas

- Node.js, TypeScript, NestJS
- React, Flutter Web/PWA, Electron, Astro
- PostgreSQL, Prisma, Redis, pgvector
- Python, Flask, XGBoost, PyOD, SHAP
- Docker, Nginx, VPS y CI/CD

## Estructura del portafolio

```text
index.md                 Portada
projects/index.md        Índice de proyectos
projects/*.md            Fichas técnicas individuales
about.md                 Perfil profesional
contact.md               Contacto
assets/css/style.scss    Personalización visual
```

El sitio está construido con Jekyll y GitHub Pages sobre una personalización del tema Leaf.
